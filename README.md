# Nexa Fiscal — landing page (React + TypeScript + Vite)

    npm install
    npm run dev      # desenvolvimento
    npm run build    # gera a pasta dist/ para deploy (Vercel, Netlify, GitHub Pages)

Edite o número do WhatsApp e a mensagem em `src/config.ts`.
Textos de serviços, FAQ e etapas ficam em `src/data.ts`.
